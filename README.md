One sharp, funny loading-screen tip for stressed developers and AI coding agents (111 characters):

> Tip: the loading bar is not stuck — your agent is re-reading your code and quietly judging your variable names.

The joke is a turn, not a pun: the bar isn't stuck, the delay has a cause — and the cause is the agent silently judging your variable names. It speaks to both audiences at once (the developer feels seen, the agent is the one doing the judging), and it flips the usual direction — here the agent reviews the human. No coffee, deadline, or compile joke. This Python 3.13 program writes that single line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It writes exactly the tip to `/output/entry.txt` — no trailing newline, no extra whitespace — then reads the file back and verifies it byte-for-byte.
